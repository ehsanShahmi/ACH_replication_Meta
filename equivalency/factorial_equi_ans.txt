If the function is called with a negative integer (e.g., `factorial(-1)`), the two versions behave differently:

1.  **First Version:** The code checks `if (n < 0)` and immediately returns `0`.
2.  **Second Version:** The input validation for negative numbers is removed. Additionally, the loop counter `i` is changed to `unsigned int`. When comparing `unsigned int i` to `int n` (where `n` is negative), `n` is promoted to a large unsigned value (e.g., -1 becomes `UINT_MAX`). Consequently, the condition `i <= n` evaluates to true, and the loop runs billions of times, causing the program to hang or consume excessive CPU resources (Denial of Service), instead of returning 0.
