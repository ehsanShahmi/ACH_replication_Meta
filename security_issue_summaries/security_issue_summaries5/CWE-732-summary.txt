mm: Tighten x86 /dev/mem with zeroing reads  Under CONFIG_STRICT_DEVMEM, reading System RAM through /dev/mem is disallowed. It was possible for heap to end up getting allocated in low 1MB RAM, and then read by things like x86info or dd, which would trip hardened usercopy:  usercopy: kernel memory exposure attempt detected from ffff880000090000 (dma-kmalloc-256) (4096 bytes)  This changes the x86 exception for the low 1MB by reading back zeros for System RAM areas instead of blindly allowing them.
