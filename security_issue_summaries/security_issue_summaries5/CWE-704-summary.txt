n_tty: fix EXTPROC vs ICANON interaction with TIOCINQ (aka FIONREAD)  We added support for EXTPROC back in 2010 in commit 26df6d13406d ("tty: Add EXTPROC support for LINEMODE") and the intent was to allow it to override some (all?) When this bit is set, several aspects of the terminal driver          are disabled. but the problem turns out that "several aspects of the terminal driver are disabled" is a bit ambiguous, and you can really confuse the n_tty layer by setting EXTPROC and then causing some of the ICANON invariants to no longer be maintained. This basically makes TIOCINQ match the case of read: if EXTPROC is set, we ignore ICANON.
