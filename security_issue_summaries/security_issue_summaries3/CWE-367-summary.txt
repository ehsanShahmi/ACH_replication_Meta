nfc: replace improper check device_is_registered() in netlink related functions  The device_is_registered() in nfc core is used to check whether nfc device is registered in netlink related functions such as nfc_fw_download(), nfc_dev_up() and so on. (cleanup task)         |     (netlink task)                           | nfc_unregister_device     | nfc_fw_download  device_del               |  device_lock   ...                     |   if (!device_is_registered)//(1)   kobject_del//(2)        |   ...  ...                      |  device_unlock  The device_is_registered() returns the value of state_in_sysfs and the state_in_sysfs is set to zero in kobject_del(). This patch uses bool variable instead of device_is_registered() to judge whether the nfc device is registered, which is well synchronized.
